Privacy Policy

Last updated: November 3, 2026

This Privacy Policy explains how Museum Shorts Uploader (the "API Client"), operated by the owner of the YouTube channel "Museum of History & Culture" (the "Operator"), handles information.

1. Use of YouTube API Services

The API Client uses YouTube API Services. By using the API Client, users agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

2. Who uses the API Client

The API Client is used only by the Operator to manage the Operator's own YouTube channel. It is not offered to the public.

3. Information accessed

  • Basic channel information of the Operator's own channel (channel ID and title), used only to confirm that the correct channel is connected.
  • Video upload: the API Client uploads the Operator's own video files and sets their title, description, tags, category, privacy status and scheduled publish time.

The API Client does not access, collect or store data about viewers or any other YouTube users.

4. Storage

The OAuth access/refresh token and a simple upload log (date, video ID, title) are stored only on the Operator's own computer. No data is sent to any server other than Google's.

5. Sharing

The Operator does not sell, share or disclose any information obtained through YouTube API Services to third parties.

6. Cookies

The API Client does not use cookies and does not place any information on users' devices other than the locally stored token described above.

7. Revoking access

Access granted to the API Client can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the stored token is deleted.

8. Contact

museum.history.culture@gmail.com
